= Quick start for Google Cloud NetApp Volumes
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Get started with Google Cloud NetApp Volumes by assigning your NetApp Console role, adding credentials, and discovering a system.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] link:task-add-roles.html[Assign roles]

[role="quick-margin-para"]
From the NetApp Console, assign the correct roles to members. For details, see link:https://docs.netapp.com/us-en/console-setup-admin/concept-identity-and-access-management.html#netapp-console-organizational-components[Learn about NetApp Console identity and access management^].


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] Add credentials

[role="quick-margin-para"]
In the NetApp Console, add Google Cloud NetApp Volumes credentials.
For details, see link:https://docs.netapp.com/us-en/data-services-workloads/add-credentials-gcnv.html[Add Google Cloud NetApp Volumes credentials to NetApp Workload Factory].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] link:task-create-system.html[Add a system]

[role="quick-margin-para"]
In the NetApp Console, discover a system using the credentials, Google Cloud project, and supported region.
