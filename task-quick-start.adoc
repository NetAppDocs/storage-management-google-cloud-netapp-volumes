= Quick start for Google Cloud NetApp Volumes
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
Get started with Google Cloud NetApp Volumes by assigning your NetApp Console role, adding credentials, and discovering a system.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] link:task-add-roles.html[Assign roles]

[role="quick-margin-para"]
From the NetApp Console, assign the correct roles to members.


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html[Add credentials]

[role="quick-margin-para"]
In the NetApp Console, add Google Cloud NetApp Volumes credentials.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] link:task-create-system.html[Add a system]

[role="quick-margin-para"]
In the NetApp Console, discover a system using the credentials, Google Cloud project, and supported region.
